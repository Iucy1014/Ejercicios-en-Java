# Ejercicios-en-Java
Código para Matriz: Llena una matriz de 10x10 con números aleatorios y recórrela en orden inverso. Cada 10 elementos, muestra un mensaje que indique el progreso del conteo.  Algoritmos:  Genera números pares entre p y q. Calcula los primeros z múltiplos de 3. Suma los primeros m múltiplos de 7 y los primeros n múltiplos de 9.
